# GitHub Submission Checklist

- [ ] Confirm the repository name, description, and owner.
- [ ] Upload the documentation files; do not upload the ZIP as a single repository file.
- [ ] Review and sanitize the real WorkBuddy skill source before adding it.
- [ ] Add a short `skill/README.md` explaining what is and is not published.
- [ ] Select authentic evidence images, confirm rights, and redact private information in public copies.
- [ ] Reconcile the public README with actual evidence and video claims.
- [ ] Add a video link only after confirming judges can open it without sign-in or a permission request.
- [ ] Verify there are no secrets, personal information, proprietary client data, or unrelated files in commit history.
- [ ] Change visibility to Public **only if required for the competition and after review**.
- [ ] Open the final URL in a private/incognito browser window to verify accessibility.
- [ ] Save the GitHub repository URL and submission confirmation.
